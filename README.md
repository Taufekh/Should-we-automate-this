# Should We Automate This?

A one-page decision framework from HUBBU, built to help real estate teams decide in 10 minutes whether to automate a task now, pilot it, or fix the process first.

Building augmentation systems for real estate teams.

## What's inside

`HUBBU-Should-We-Automate-This.pdf` walks through:

1. **Define the task** -- name it, place it, and name the pain it causes
2. **Red-flag check** -- signals that mean a task should stay human-led
3. **Score the task** -- a 1-5 rubric across seven criteria
4. **Decision rule** -- turn the score into automate now, pilot, or wait
5. **Automation blueprint** -- trigger, input, action, checkpoint, exception path, output, metric, owner
6. **Real estate examples** -- good and bad candidates for full automation
7. **Example in action** -- a worked example using a new rents onboarding workflow
8. **Run it today** -- a 9-step checklist to apply the framework immediately

## Who this is for

Real estate operators, brokers, and team leads who want a fast, repeatable way to decide where automation actually helps, and where it does not.

## Use it

Download the PDF and work through it against one task you already find painful. Score it, apply the decision rule, and if it passes, fill out the blueprint before you build anything.
